# Ride-Hailing (Taxi) API 🚖

Полнофункциональный REST API сервис для службы заказа такси, разработанный с использованием **Django REST Framework**, **Docker**, **PostgreSQL** и **Redis**. Проект включает в себя полноценную ролевую систему авторизации (пассажиры и водители), управление поездками и готовый фронтенд-демо интерфейс для тестирования.

---

## 🛠 Технологический стек

- **Backend:** Python, Django, Django REST Framework (DRF)
- **Авторизация:** SimpleJWT (JSON Web Tokens)
- **База данных:** PostgreSQL
- **Кеширование / Очереди:** Redis
- **Контейнеризация:** Docker, Docker Compose
- **Frontend (Demo):** HTML5, JavaScript (Fetch API)

---

## 🚀 Архитектура и функционал

1. **Модуль аутентификации (`authentication`):** Регистрация пользователей с выбором роли (`passenger` или `driver`) и защищенный вход через JWT.
2. **Модуль водителей (`drivers`):** Управление профилями и статусами водителей.
3. **Модуль поездок (`rides`):** 
   - Создание заказа пассажиром (начальная и конечная точки, расчет стоимости).
   - Просмотр списка доступных заказов.
   - Принятие заказа водителем и обновление статусов.
4. **Безопасность:** Настроенные CORS-политики и защита эндпоинтов с помощью `IsAuthenticated`.
